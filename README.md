# Neural Networks

Playground for learning about training networks. First two examples can be viewed at tag `single-and-multi-neuron-network` which isn't very efficient, but I had to start somewhere since I started from no knowledge on this subject pretty much. After that I used some abstraction and laid out data in a much more optimal way.

As for visualisations, since they aren't the point of this repo and this is mainly just for my curious exploration, the visualisations have been made using AI without really looking at the quality of the code on that part. I have made sure to seperate the actual neural net and the visualisations for (amonst others) this reason.
